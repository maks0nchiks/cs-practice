git log --oneline --stat



Показывает историю коммитов в кратком виде и статистику изменений файлов: сколько строк добавлено и удалено.



git diff HEAD\~2 HEAD -- lab03/calc.py



Сравнивает файл calc.py между коммитом двух шагов назад и текущим коммитом. Строки с + добавлены, строки с - удалены.



git show HEAD\~1



Показывает информацию о предыдущем коммите, включая автора, дату, сообщение и внесённые изменения. В моём случае коммит добавил вычитание в калькулятор.



git log -S"def" --oneline -- lab03/calc.py



Ищет коммиты, в которых изменилось количество вхождений текста def в файле. В моём случае команда ничего не вывела, потому что таких изменений не нашлось.



git blame lab03/calc.py



Показывает для каждой строки файла коммит, автора и дату последнего изменения строки.



git restore calc.py отменяет незакоммиченные изменения файла и восстанавливает его из индекса.

git restore --source=HEAD\~2 calc.py восстанавливает содержимое файла из коммита, который находится на два коммита раньше текущего.

git diff -- calc.py показывает отличия рабочей копии от текущего коммита.



Команда git restore --source=HEAD\~2 calc.py не перемещает ветку и не удаляет коммиты — она меняет только содержимое файла в рабочей копии.
