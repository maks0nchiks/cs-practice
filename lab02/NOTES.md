Рабочая папка — это файлы проекта на компьютере, с которыми я работаю и которые могу изменять.



Индекс — это область, в которую я добавляю изменения, подготовленные для следующего коммита. Команда git add добавляет изменения в индекс.



Коммит — это сохранённый снимок подготовленных изменений в истории Git. У него есть уникальный идентификатор, автор и сообщение.



Git — это система контроля версий, которая хранит историю изменений проекта и позволяет работать с ветками.



GitHub — это онлайн-платформа, на которой можно размещать Git-репозитории, публиковать историю изменений и совместно работать над проектами.
