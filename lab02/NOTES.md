Рабочая папка — это файлы проекта на компьютере, с которыми я работаю и которые могу изменять.

Индекс — это область, в которую я добавляю изменения, подготовленные для следующего коммита. Команда git add добавляет изменения в индекс.

Коммит — это сохранённый снимок подготовленных изменений в истории Git. У него есть уникальный идентификатор, автор и сообщение.

Git — это система контроля версий, которая хранит историю изменений проекта и позволяет работать с ветками.

GitHub — это онлайн-платформа, на которой можно размещать Git-репозитории, публиковать историю изменений и совместно работать над проектами.

git status — показывает состояние рабочей папки и индекса, в том числе изменённые, подготовленные и неотслеживаемые файлы.

git diff — показывает изменения в рабочей папке, которые ещё не добавлены в индекс.

git diff --staged — показывает изменения, уже добавленные в индекс, относительно последнего коммита.

Ветка — это отдельная линия разработки, которая позволяет работать над изменениями независимо от других веток.

При создании нового коммита ветка перемещается на этот коммит, поэтому история изменений в ней продолжается.

Слияние (merge) — это объединение изменений из одной ветки с другой. После слияния изменения из объединяемой ветки становятся частью истории целевой ветки.
